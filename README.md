v# Real-Time Dashboard

A full-stack real-time dashboard using:

- **Frontend:** React + TypeScript + TailwindCSS
- **Backend:** FastAPI + REST APIs
- **API Examples:** Crypto, Weather, etc.

## Project Structure
realtime-dashboard/
├── frontend/ # React app
├── backend/ # FastAPI app
## Setup

### Frontend
```bash
cd frontend
npm install
npm start

### Backend
cd backend
source venv/bin/activate
uvicorn main:app --reload
